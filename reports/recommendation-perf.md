# 추천 API 응답 시간 측정

> `./gradlew perfTest` (`RecommendationPerformanceTest`) 가 다시 만든다. 기획서 5-6 목표: 캐시 미스 p95 300ms, 캐시 히트 p95 50ms 이하.
> 측정은 MockMvc 로 컨트롤러·보안 필터·직렬화까지 포함한 서버 내부 처리 시간이며 네트워크 왕복은 빠져 있다.
> 데이터는 고정 시드 난수로 만든 가상 데이터다.

## 환경

| 항목 | 값 |
|---|---|
| 측정일 | 2026-10-17 |
| CPU 코어 | 12 |
| Java | 21.0.5 |
| DB | 로컬 MySQL 8.0.43 |

## 데이터

| 항목 | 값 |
|---|---|
| 원두 | 1,000 |
| 사용자 | 1,001 |
| 노트 | 10,010 |
| 원두 벡터 전체 재계산 | 1,000개 / 590 ms |
| 데이터 준비 전체 | 115,773 ms |

## 결과 (GET /api/v1/recommendations, 반복 200회, 예열 30회)

| 구분 | p50 | p95 | p99 | 최대 | 목표 (p95) |
|---|---|---|---|---|---|
| 캐시 미스 | 42.7 ms | **65.6 ms** | 77.6 ms | 89.8 ms | 300 ms |
| 캐시 히트 | 5.9 ms | **9.7 ms** | 14.2 ms | 23.2 ms | 50 ms |

캐시 미스 한 번에 하는 일: 저장된 취향 벡터 읽기 → 제외 대상·탐험용 이력 조회 → 후보 원두 벡터 전체(약 1,000개) 읽기 →
가중 코사인 점수 계산·정렬 → 상위 10개 원두 요약 조회 → 추천 이유 생성.
